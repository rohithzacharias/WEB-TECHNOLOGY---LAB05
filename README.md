# Experiment 05 – DOM Elements and Events

## Description
This experiment demonstrates DOM manipulation and event handling using JavaScript through six interactive exercises in a TechZone Electronic Store webpage.

## Exercises
1. Product Name Analyzer
2. Warranty Calculator
3. Dynamic Product Showcase
4. Currency Converter
5. Lucky Draw Spinner
6. Shopping Cart Checkout

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling
